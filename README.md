# ToDo API

Сервис для хранения задач по принципу матрицы Эйзенхауэра. Задачи разделяются по четырём квадрантам на основании пометки «Важная» от пользователя и количества дней до конца задачи. Если дедлайн по задаче менее, чем через 3 дня, задача помечается как срочная.

Приложение самостоятельно вычисляет квадрант на основании данных, предоставленных пользователем. Это позволяет удобно отслеживать текущее их положение в матрице и приоритезировать выполнение наиболее важных задач.

## Реализация

Использует Fast API и Uvicorn для реализации HTTP API. Для запуска нужно использовать команду:

```shell
uvicorn main:app --reload
```

Документация по API (Swagger UI) доступна по пути /docs.

## Возможности

* Аутентификация с использованием JWT
* Статистика по задачам
* Распределение задач по матрице Эйзенхауэра
* Поиск по задачам

## Хранение данных

Для хранения данных используется PostgreSQL.
